# AI és ML fogalomtár

## Determinisztikus rule score

Kézzel definiált, reprodukálható pontozás. Azonos input és konfiguráció azonos
eredményt ad.

## Supervised learning

Felügyelt tanulás, ahol a modell historikus példákból tanul input feature-ök és
célváltozó alapján.

## Leakage

Adatszivárgás. Trading rendszerben különösen veszélyes, ha a modell olyan
információt kap, amely a döntés pillanatában még nem volt ismert.

## Walk-forward validation

Idősoros validáció, ahol a modell múltbeli időszakon tanul, majd későbbi
időszakon kerül tesztelésre.
